description: Add a site, weighbridge, product, customer, job or truck
---

Run `npm run quarry -- add site|bridge|product|customer|job|truck ...` (see `npm run quarry -- help`). A truck needs its tare and maximum gross mass; a job needs its customer, product and price. Read the record back after the change and show it. If a name is ambiguous, list the candidates and ask which one.
